## 🚀 Projects

### 🚗 Used Car Price Prediction

A machine learning project for predicting the resale price of used cars from details such as company, model, year, kilometers driven and fuel type.

**What I worked on:**

- Data cleaning and preprocessing
- Exploratory data analysis
- Feature engineering
- Comparing different regression models
- Hyperparameter tuning
- Model evaluation using R², MAE and RMSE
- Building a simple Flask interface to test predictions

**Tech:** Python, Pandas, NumPy, Scikit-learn, Flask

🔗 [View Project](https://github.com/mahadev0406/Car-price-prediction)

**Features:**

- Automatic attendance marking
- Flask dashboard
- CSV-based attendance records

**Tech:** Python, OpenCV, Flask
