# 🚀 Featured Projects

## 🛣️ RoadGuard AI

**AI-Based Road Distress Detection, Severity Assessment, Pavement Condition Analysis & Maintenance Prioritization**

RoadGuard AI is a computer vision system designed to analyze road conditions from vehicle-camera imagery and support data-driven road maintenance decisions.

### 🔍 What it does

- Detects road distress using **YOLOv8**
- Identifies longitudinal cracks, transverse cracks, alligator cracks, and potholes
- Estimates damage severity using detection and geometric information
- Generates a road-condition score
- Prioritizes maintenance based on damage severity and road condition
- Supports spatial-temporal tracking to reduce duplicate detections from video
- Includes a dashboard for visualizing road-condition information

### 🧠 Technical Work

- Dataset preparation and validation
- Stratified train/validation splitting
- YOLOv8 object detection
- Data augmentation
- Severity scoring
- Road-condition indexing
- Maintenance prioritization
- Video tracking
- Model evaluation and error analysis

### 📊 Model Results

**YOLOv8n on the RDD2022 India subset**

- mAP@50: **58.4%**
- mAP@50–95: **34.2%**
- Precision: **62.1%**
- Recall: **54.8%**
- CPU latency: **~24 ms**

The project also analyzes important failure cases such as thin cracks, shadows, wet pavement, and domain differences between asphalt and concrete.

**Tech:** Python, YOLOv8, OpenCV, Flask, Computer Vision, Machine Learning

🔗 [View Project](https://github.com/mahadev0406/RoadGuard-AI)

A machine learning project for **land-cover classification using hyperspectral remote sensing data** from the **Indian Pines dataset**.

### 🔬 Approach
